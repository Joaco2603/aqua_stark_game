## 🚀 Uso Básico (3 pasos)

### 1️⃣ Crear GameObject del sistema
```
Crea "DecorationSystem" → Asigna DecorationSceneSetup.cs
```

### 2️⃣ Asignar referencias en Inspector
```
aquariumTransform    → Tu acuario
uiCanvas            → Tu Canvas
decorationPrefabs[] → Tus modelos 3D
decorationIcons[]   → Tus iconos PNG
```

### 3️⃣ Play y listo
```
El script DecorationSceneSetup automatiza todo
```

## 🐛 Troubleshooting

| Problema | Solución |
|----------|----------|
| No aparece inventario | Verifica que uiCanvas está asignado |
| Preview no sigue ratón | Main Camera debe tener tag "MainCamera" |
| Decoraciones desaparecen | Verifica aquariumParent está asignado |
| No se consume del inventario | Revisa consola para errores |
